치환 결과 비교

입력한 문장이나 텍스트 파일의 마스킹 결과를 확인하고 원문과의 대응을 살펴봅니다.

◈ 안내 및 주의사항

  • 대화 분리: 미리보기 별칭은 실제 대화의 이전 별칭과 독립적이며 새로 발급됩니다.
  • 첨부파일 차단 유지: 여기서 파일을 읽어볼 수 있다는 사실이 Claude/Codex 첨부파일이 보호된다는 의미가 아닙니다. 첨부파일·이미지·바이너리는 계속 지원되지 않으며 차단됩니다.
  • 강제 규칙 우선: 자동 감지가 모든 비밀을 찾아내지 못하며, 설정된 강제 치환 규칙이 항상 우선 적용됩니다.
  • 로컬 확인: 원문이 화면에 표시되는 것은 사용자가 로컬에서 명시적으로 확인을 요청했기 때문입니다. 외부 모델이나 로그로 전송되지 않습니다.
  • 단일 파일 제한: 1차 구현에서는 한 번에 1개의 로컬 텍스트 파일(최대 256 KiB UTF-8)만 지원합니다.

PDF, DOCX, 이미지, 압축파일(ZIP) 및 바이너리/원격 URL은 지원하지 않습니다.

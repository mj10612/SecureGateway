치환 결과 비교

입력한 문장이나 텍스트 파일의 마스킹 결과를 확인하고 원문과의 대응을 살펴봅니다.

◈ 안내 및 주의사항

  • 대화 분리: 미리보기 별칭은 실제 대화의 이전 별칭과 독립적이며 새로 발급됩니다.
  • 첨부파일 차단 유지: 여기서 파일을 읽어볼 수 있다는 사실이 Claude/Codex 첨부파일이 보호된다는 의미가 아닙니다. 첨부파일·이미지·바이너리는 계속 지원되지 않으며 차단됩니다.
  • 강제 규칙 우선: 자동 감지가 모든 비밀을 찾아내지 못하며, 설정된 강제 치환 규칙이 항상 우선 적용됩니다.
  • 로컬 확인: 원문이 화면에 표시되는 것은 사용자가 로컬에서 명시적으로 확인을 요청했기 때문입니다. 외부 모델이나 로그로 전송되지 않습니다.
  • 단일 파일 제한: 1차 구현에서는 한 번에 1개의 로컬 텍스트 파일(최대 256 KiB UTF-8)만 지원합니다.

PDF, DOCX, 이미지, 압축파일(ZIP) 및 바이너리/원격 URL은 지원하지 않습니다.

CONTENT AUDIT OBSERVABILITY

치환·복원 감사

실제 게이트웨이 요청의 원문, 치환 송신, 응답 및 도구 복원 내역을 사후에 검증합니다.

저장소 잠김

◈ 안내 및 주의사항

  • 실제 발생 내역: 이 화면은 실제로 처리된 요청·응답·도구 호출의 사후 감사 기록입니다. #342 미리보기(가상 시험)와 구별됩니다.
  • 외부 도구 통신 미감사: 게이트웨이를 거치지 않은 외부 도구 자체의 직접 통신은 감사하지 않으며 관측된 범위만 표시합니다.
  • 첨부파일·이미지 미지원: 이미지·바이너리·원격 첨부파일은 게이트웨이에서 지원되지 않으며 차단된 사실만 안전한 메타데이터로 남깁니다.
  • 문장 속 비밀: 일반 문장 속에 평문으로 작성된 비밀번호나 키는 자동 패턴 탐지로 인식되지 않을 수 있으며 암호화되어 저장될 수 있습니다.
  • 로컬 확인: 원문과 복원 결과는 관리자의 명시적 요청으로 로컬에서만 복호화되어 표시됩니다. 외부 모델이나 클라우드로 전송되지 않습니다.

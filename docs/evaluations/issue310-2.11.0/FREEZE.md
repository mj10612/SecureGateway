# Frozen regression replay protocol, 2.10.0

Frozen before the replay: the previously committed `../accuracy-20261109/development-cases.json` and `../accuracy-20261109/holdout-cases.json` contain synthetic source inputs, offsets, public spans, rubrics and trusted local policies. Select both cases per split and issue (four cases per issue), one baseline and one candidate per case. Run `uv run --locked --all-extras python docs/evaluations/issue310-2.11.0/replay.py OUTPUT_DIR`, which uses the existing loopback HTTP evaluator and stores each engine payload, exact restoration, gold-span counts and separate baseline/candidate numerators and denominators. Maximum 60 seconds per arm/case. Do not treat missing/error captures as protected.

The earlier holdout and its previous results were inspected before this work; these are regression replays, not independent untouched holdout or evidence of generalization. Freeze the existing protocol's no-new-exposure and no-integrity-regression rules, two fresh interpreter repeats per family/arm, 16 interpretations and 16 separate grades per candidate, and the existing 1.25× baseline + 5 ms warm p95 / 32 MiB screening guards. No candidate can be adopted on this replay alone. Real interpreter and guessing results for the modified candidates are unmeasured until actually run; latency and memory guards are unmeasured unless separately collected.

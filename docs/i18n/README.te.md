SecureGateway మద్దతు ఉన్న పాఠ్యం, సోర్స్ కోడ్‌ను AI ప్రొవైడర్‌కు పంపే ముందు స్థానికంగా మాస్క్ చేస్తుంది. స్థానిక Gateway సమాధానాలు, టూల్ ఆర్గ్యుమెంట్‌లను అసలు రూపంలో పునరుద్ధరిస్తుంది. మ్యాపింగ్‌లు స్థానిక మెమరీలో లేదా గుప్తీకరించిన స్థానిక స్నాప్‌షాట్‌లలో ఉంటాయి.

## ఇన్‌స్టాలేషన్

Python 3.10 లేదా కొత్త వెర్షన్, uv, Git సిద్ధం చేసి ముందుగా Claude Code లేదా Codexలో లాగిన్ అవ్వండి. ఇన్‌స్టాలేషన్ లాగిన్ ఫైల్‌లను ఉంచుతూ యూజర్ స్థాయి ప్రొవైడర్ సెట్టింగ్‌లు, ఆటోమేటిక్ స్టార్టప్‌ను ఏర్పాటు చేస్తుంది. తర్వాత AI క్లయింట్‌ను మళ్లీ ప్రారంభించండి. మొదటి పరీక్ష కోసం ఇన్‌స్టాలేషన్‌కు ముందు ఉన్న సంభాషణను కొనసాగించకుండా కొత్త సంభాషణ ప్రారంభించండి.

```sh
git clone https://github.com/mj10612/SecureGateway.git
cd SecureGateway
uv tool install .
```

కమాండ్ కనబడకపోతే `uv tool update-shell` అమలు చేసి టెర్మినల్‌ను మళ్లీ తెరవండి.

```sh
secure-gateway gateway install --agent both
secure-gateway gateway status
```

## వినియోగం

ఈ ఉదాహరణ తెలుగును స్పష్టంగా ఎంచుకుంటుంది. Gateway పాఠ్యం కోసం ప్రస్తుతం ఉన్న కాన్ఫిగరేషన్‌లో natural_language విలువను teగా పెట్టండి, ఇతర ఫీల్డ్‌లను అలాగే ఉంచి Gatewayను మళ్లీ ప్రారంభించండి. సోర్స్ కోడ్‌లోని సంఖ్యలు డిఫాల్ట్‌గా అలాగే ఉంటాయి. gateway diagnostics సెషన్‌ల మొత్తం పరిమితులను చూపిస్తుంది.

```sh
secure-gateway mask "సమీక్ష కోసం ఉదాహరణ పత్రం" --language te --json-output
secure-gateway gateway diagnostics
```

## పరిధి మరియు పరిమితులు

భాషా మద్దతు పద విశ్లేషణ ఆధారితమైనది; మాస్కింగ్ అంచనా నియమాలను ఉపయోగిస్తుంది. ఖచ్చితమైన పునరుద్ధరణ జరిగినా మాస్క్ చేసిన కోడ్ ప్రవర్తన అంతా అలాగే ఉంటుందని హామీ లేదు. చిత్రాలు, మద్దతు లేని రిమోట్ అటాచ్‌మెంట్‌లు నిరోధించబడతాయి. uncommon_wordsలో అంతర్నిర్మిత సాధారణ పదజాలం ఇంగ్లీష్, కొరియన్‌లకు మాత్రమే ఉంది; ఇతర భాషల్లో కంటెంట్‌ను జాగ్రత్తగా మాస్క్ చేస్తుంది. MCP సర్వర్‌ను జోడించడం మాత్రమే ప్రాంప్ట్‌లను అడ్డుకోదు. మోడల్ సందర్భం బయట విశ్వసనీయ స్థానిక యాప్‌లో పునరుద్ధరించండి.

## ఆపడం మరియు తొలగించడం

సెట్టింగ్‌లను తొలగించే ముందు సేవను ఆపండి. అన్‌ఇన్‌స్టాలేషన్ నిర్వహించిన సెట్టింగ్‌లను పునరుద్ధరిస్తుంది; తర్వాత యూజర్ చేసిన మార్పులను ఓవర్‌రైట్ చేయదు. హోస్ట్ సెట్టింగ్‌లకు నేరుగా సింబాలిక్ లింక్‌లకు బదులు సాధారణ ఫైల్‌లను వాడండి. అప్‌డేట్, రికవరీ కోసం ప్రధాన గైడ్ చూడండి.

```sh
secure-gateway gateway stop
secure-gateway gateway uninstall
uv tool uninstall secure-gateway
```

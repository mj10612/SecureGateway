SecureGateway локально маскирует поддерживаемый текст и исходный код перед отправкой провайдеру ИИ. Локальный Gateway восстанавливает ответы и аргументы инструментов. Таблицы соответствий хранятся в локальной памяти или зашифрованных локальных снимках.

## Установка

Подготовьте Python 3.10 или новее, uv и Git, затем войдите в Claude Code или Codex. Установка меняет пользовательские настройки провайдера и включает автозапуск, сохраняя файлы входа. После установки перезапустите клиент ИИ. Для первой проверки начните новый разговор, а не продолжайте разговор, созданный до установки.

```sh
git clone https://github.com/mj10612/SecureGateway.git
cd SecureGateway
uv tool install .
```

Если команда не найдена, выполните `uv tool update-shell` и заново откройте терминал.

```sh
secure-gateway gateway install --agent both
secure-gateway gateway status
```

## Использование

Пример явно выбирает русский язык. Для текста Gateway установите natural_language в ru в существующей конфигурации, сохраните остальные поля и перезапустите Gateway. Числа в исходном коде по умолчанию сохраняются. gateway diagnostics показывает общие лимиты сеансов.

```sh
secure-gateway mask "Пример документа для проверки" --language ru --json-output
secure-gateway gateway diagnostics
```

## Возможности и ограничения

Поддержка языков основана на лексическом анализе, а маскирование является эвристическим. Точное восстановление не гарантирует сохранение всего поведения маскированного кода. Изображения и неподдерживаемые удалённые вложения блокируются. Встроенный общеупотребительный словарь uncommon_words есть только для английского и корейского; для других языков применяется консервативное маскирование содержимого. Добавление MCP-сервера само по себе не перехватывает запросы. Восстанавливайте данные в доверенном локальном приложении вне контекста модели.

## Остановка и удаление

Остановите службу перед удалением настроек. Удаление восстанавливает управляемые настройки и отказывается перезаписывать последующие изменения пользователя. Используйте обычные файлы настроек вместо прямых символических ссылок. Обновление и восстановление описаны в основном руководстве.

```sh
secure-gateway gateway stop
secure-gateway gateway uninstall
uv tool uninstall secure-gateway
```

# Dictionary source collection (2026-11-09)

No repository files changed. Candidate pools only, not reviewed supplier dictionaries.

Each domain-candidates.json combines individually attributable Wikidata structured labels (CC0), NASA subject terms (US government work public use permitted, attribution requested), and CPC classification titles (CPC Linked Open EP data CC BY4.0; official title ZIP2026.08). Counts identify records rather than independent accepted concepts. CPC titles often have relative clauses and require headword extraction; do not activate them verbatim. WD military/semiconductor trees include product/platform models, requiring generic-vs-product review. NASA descendant terms have narrow technical scope, not complete domain coverage. No copyrighted definitions copied.

Preferred machine input: defense-candidates.json, automotive-candidates.json, semiconductor-candidates.json; sources/rights in source-manifest.json; counts in candidate-counts.json.
